3 · Read

URLs that return data

An API is a URL that returns data instead of a web page. Chicago runs a public one — data.cityofchicago.org — publishing libraries, 311 requests, inspections, licenses. Every dataset shows its API endpoint under Export → API.

The pull is four moves: requests.get(url) asks; r.status_code answers (200 = OK, 404 = wrong address); r.json() parses the reply into Python objects — dictionaries in lists, the nested shapes you met in the Python course; and pd.json_normalize(data) flattens them into a DataFrame. City servers to your table, four lines.

Two professional habits ride along. Check the status before trusting the data — a 200 with three rows can still mean a rate limit truncated you. And keep a plan B: endpoints change, wifi drops mid-class; the notebook carries a small backup dataset so the lesson survives the real world. Knowing when to fall back is itself a data skill — the same one that will matter when a nonprofit's spreadsheet export fails the night before a board meeting.
