3 · Read & play

The call, the blocks, the meter

Every AI app you've used is code making this exact call. The library is anthropic; the client reads your key from the environment; the request is client.messages.create(model=…, max_tokens=…, messages=[…]) — a list of messages in, a response out.

The response is a list of content blocks, not a plain string. Loop over response.content, check each block.type, take the text from the text blocks. Check response.stop_reason too: end_turn means it finished; max_tokens means your ceiling cut it off; refusal is the manners school from How AI Works, appearing in your own code.

The key is a house key. It's identity and money in one string. It goes in via getpass (hidden as you paste), never typed into a cell — a key pasted into a notebook that lands on GitHub is found by scraper bots in minutes.

Tokens are the meter. response.usage shows tokens in and out; both cost real money from the class key. Small max_tokens while learning isn't stinginess — it's professionalism with a shared resource.
