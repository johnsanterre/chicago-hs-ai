3 · Read & play

selector { property: value; }

CSS is rules: a selector picks elements, properties set their look. h1 { color: #174A6C; } — every h1, that navy. Put rules in a <style> block in the head for now; real projects move them to a separate file later.

The properties that carry a page: font-family (system-ui is the clean default), color and background, line-height (1.5–1.7 for reading), max-width (~60ch keeps lines readable), padding and margin (space inside vs outside). Ten properties in, you can make anything presentable.

Use the AI the way lesson 5 of How AI Works taught: ask for options — three complete looks, one calm, one bold, one weird — then choose and iterate. The machine generates; your taste selects. And the readable-beats-flashy rule wins arguments: contrast high, lines short, spacing generous.

4 · Do it

Three looks, one choice

1. Hand-write five CSS rules on your about page first — feel the syntax.

2. Ask your AI for three complete looks (calm / bold / weird). Try each in the loop.

3. Choose one, then coach it through three iterations ("more contrast," "bigger headings," "less purple").

4. Read the final style block line by line — deletion-test anything mysterious.
