3 · Read

The file, the browser, the loop

A web page is a plain text file with an .html ending. The browser reads it top to bottom and draws what it says. No compiler, no install, no build step — the browser is the most forgiving programming environment ever shipped, and it's already on every machine you touch.

Your editor is vscode.dev — real VS Code, running in a browser tab, works on a Chromebook. Open a folder, keep your files in it, and know that the same editor (installed) is what professionals use all day.

The whole craft runs on one loop: edit → save → refresh. You change the file, save it, refresh the browser tab showing it, and see the result in two seconds. Fast loops are why the web is the best place to learn to build.

One rule carried from the How AI Works course, now with teeth: your AI pair will happily write whole pages. Fine — but you read every line you keep, and if you can't explain a line, you ask until you can. The next two lessons train exactly that.

4 · Do it

Zero to page

1. Open vscode.dev, open a folder (create my-site).

2. New file hello.html. Type — don't paste — <h1> your name </h1> and a <p> sentence.

3. Open the file in a browser tab. Run the loop five times: change, save, refresh.

4. Ask your AI: "what are the 5 HTML tags a beginner should know first?" Try each one in your file, one loop at a time.
