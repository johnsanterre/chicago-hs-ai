Learn to build with AI · then build for Chicago

Ten courses. Start with any of them.

Short lessons you scroll straight through — a video, a listen, a read, code you run in your browser, a quick check, and something you build. No course requires another one first.

Flat by design: every course starts from zero and stands alone. Pick the one that sounds most interesting and begin.
COURSE 1 · 8 LESSONS

How AI Works

No coding required

What a language model actually is, how to talk to one well, and how to know when it's wrong. Everything else you'll ever do with AI rests on the ideas in here.

 COURSE 2 · 8 LESSONS

Code with an AI Partner

Build real web pages

Your first real builds: a website about you, made with an AI pair programmer. You'll learn to read what the AI writes, fix what it breaks, and put your work on the internet.

 COURSE 3 · 8 LESSONS

Python in Colab

Code in your browser

Python from zero, entirely in your browser, with an AI pair at your side. Every lesson ends with code you wrote, running.

 COURSE 4 · 8 LESSONS

Working with Data

Find the story in the numbers

Real, messy data: clean it, question it, and turn it into charts that tell the truth. The skill every organization — including every nonprofit in Chicago — is short on.

 COURSE 5 · 8 LESSONS

Build with LLMs

Put AI inside your code

Call a language model from your own program and build things that couldn't exist before: a chat app, a document assistant, an AI that uses tools. This is the frontier, made doable.

 COURSE 6 · 8 LESSONS

Think with AI

No coding required

Using an LLM well, every day: studying, writing, research, planning — with the honesty rules built in. The course you can use tomorrow morning, code or no code.

 COURSE 7 · 8 LESSONS

Build a Tiny Language Model

See inside — by building one

Counting, dice, temperature, context, a real training run with a falling loss, a tokenizer — ending with a model trained on a corpus you curated. Small, not fake.

 COURSE 8 · 8 LESSONS

Document Pipelines

Turn paper piles into answers

The drawer every organization has — reports, forms, minutes — becomes a clean, validated table that answers questions. Extraction, cleaning, rules, LLM extraction, validation: the most practicum-shaped course on the site.

 COURSE 9 · 8 LESSONS

Research Agents

Send an AI to find out

A chatbot answers from memory; a research agent goes and looks. The agent loop, tools, question decomposition, gathering with receipts, adversarial verification, and a report that cites every number — ending with a real research run.

 COURSE 10 · 8 LESSONS

Ask Your Documents

Answers from your own pile

The model never read your handbook — so build the system that fixes it: chunking, search by meaning with embeddings, retrieve-then-ask under a grounding contract, and a capstone tool a real user keeps.
