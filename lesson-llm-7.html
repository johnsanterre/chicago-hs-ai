3 · Read & play

Tools, the loop, and the rules

A tool is a function of yours plus a description the model reads: name, purpose, input schema. The description is a prompt — the model decides from it when your function would help.

The agent loop: send the question with the tool list; when stop_reason == "tool_use", the model is asking you to run a tool with specific inputs — run it, append the result, loop; when it stops asking, it answers with everything it learned. The model plans; your code executes; the loop mediates. Every AI agent in production is this pattern scaled up.

The rules arrive with the power. Give an agent the smallest tool that works — a lookup, not a delete. Log every call — your print statement is the baby version of the audit trail real systems keep. And put a human between the agent and anything irreversible — money, email, deletion. You'll meet these rules again the day a nonprofit hands you real systems; learn them now, on a fake schedule function, where mistakes are free.
