3 · Read

Bones, skin, muscles

The stack, complete: HTML is structure, CSS is looks, JavaScript is behavior. The core move is always the same two steps: find an element, attach a behavior. document.getElementById('hi') finds; .onclick = () => { … } attaches. Everything interactive on the web — menus, games, feeds — is that move, compounded.

Your informant is the developer console (F12, or right-click → Inspect → Console). JavaScript errors appear there with the file and line number; your own console.log("got here") messages appear there too — the flashlight you'll use constantly next lesson. A silent broken button almost always has a loud console explaining why.

JavaScript is a bigger language than HTML or CSS — variables, functions, ifs — and if you took Python in Colab you'll recognize almost everything, wearing different punctuation. Lean on your AI pair for syntax; keep the two-step model and the reading rule, and you can wire anything.
