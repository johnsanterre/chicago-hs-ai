3 · Read

Rows, columns, and the three openers

A dataset is a table: rows are things, columns are facts about them. The file format is usually CSV — comma-separated values, plain text, the lingua franca every tool speaks. The tool is pandas, Python's data library; its table object is the DataFrame (df by convention).

Three openers before any analysis: df.shape (how many rows and columns), df.columns (what facts exist), df.head() (the first rows, eyeballed). Analysts never trust a table they haven't looked at — files lie: wrong delimiters, header rows missing, a column of numbers stored as text.

One column is df['age']; one row is df.loc[2] — and rows count from zero, exactly like Python lists, because that's what they are underneath. If you took Python in Colab, everything here rides on skills you already own; if not, lesson 1 of that course gets you running in an hour.
