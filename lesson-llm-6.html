3 · Read

The eval: inputs, checks, score

An eval has three parts. Fixed inputs: the same five topics every run, so scores compare across prompt versions. Checks: plain functions taking an output and returning True or False — has the format? under the length? contains no hedging? Each encodes one property you care about. The score: outputs × checks, counted. Prompt B beats prompt A 14 to 9 ends the argument that adjectives never could.

This is precisely how professional teams work: thousands of eval cases run before any prompt or model change ships. Yours has five cases and three checks — the shape is identical, and the habit is the point: never ship a prompt change on vibes.

And the honest limit, which you knew before this course: checks verify form wonderfully and truth poorly. A wrong answer in perfect format passes every formatting check. Truth still requires sources or humans — the verification rule from How AI Works, now wearing an engineering hat.
