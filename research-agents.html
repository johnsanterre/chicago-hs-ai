Research Agents

A chatbot answers from memory; a research agent goes and looks. This course builds the whole flow — the agent loop, tools, question decomposition, gathering with receipts, claims, adversarial verification, and a report that cites every number — ending with a real research run on a question you choose.

No other course required, though Build with LLMs is the gentlest on-ramp to the API pieces. The agent mechanics run entirely offline on a bundled mini-web, so every lesson works without a key; lessons with live model calls use the class API key from the Build with LLMs setup and include precomputed outputs. Pace: one lesson a week finishes in two months; every two weeks still finishes in a semester.
