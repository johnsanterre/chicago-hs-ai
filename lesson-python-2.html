3 · Read & play

Boxes with labels

A variable is a labeled box: age = 15 puts 15 in a box labeled age. From then on, code says age and means whatever's in the box. Change the box once; every line that uses the label updates. That's the first real power of programming: change one thing, not twenty.

Text lives in quotes and is called a string. Strings add together ("a" + "b"), repeat (word * 3), and measure themselves (len(word)).

The tool to actually remember: the f-string. Put f before the quotes and drop variables into curly braces: f"{name} is {age}". It's how programs talk to humans, and you'll type it in every lesson for the rest of this course.
