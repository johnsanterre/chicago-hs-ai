3 · Read

What shipping means

GitHub Pages turns a repo into a website: Settings → Pages → choose the main branch → save. Ninety seconds later your files are served at username.github.io/repo-name — by the same system serving the course you're reading right now.

The development loop gains a final step: edit → commit → the live site updates. From now on a typo fix is a commit away from the whole world seeing the correction. That's real publishing discipline, the same one professionals ship under.

Shipping is also a line you cross: private work asks nothing of you; public work is a claim — this is mine, and I stand behind it. Check your page the way lesson 7 of How AI Works taught: content you'd defend, credits where credit is due, nothing you'd be embarrassed to own. Then ship it and feel the difference. Builders ship.

4 · Do it

Go live

1. Settings → Pages → main branch → save. Wait. Refresh.

2. Open your URL on a phone. Let that land.

3. Find one thing to improve now that it's public (there's always one). Edit → commit → watch the live site change.

4. Send the URL to one person who'll actually look.
