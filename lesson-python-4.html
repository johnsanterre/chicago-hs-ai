3 · Read

def, return, and stacking

def cheer(name): defines a function — code with a name and a parameter (the input it accepts). Call cheer("Maya") and the body runs with name set to "Maya". Write once, call forever.

return makes a function hand a value back: def area(w, h): return w * h. Now area(12, 10) is 120 anywhere you write it — store it, print it, pass it onward.

The big idea is stacking: cost() calls area(); something else calls cost(). All serious software — including the AI you're pairing with — is small functions composed into bigger ones. When you break a problem into function-sized pieces, you're doing real software design.

The build has a testable promise: decode(encode(msg)) == msg must print True. Programs that state their promises and prove them — that's where the Tests lesson of the craft courses will pick up.
