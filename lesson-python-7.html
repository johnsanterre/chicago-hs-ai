3 · Read

import — and why you built it by hand first

A library is a toolbox of functions someone already wrote. import random opens the box; random.randint(1, 6) uses a tool from it. Python ships with hundreds of boxes — dates, randomness, counting, math — and the wider world has thousands more (the data course runs on one called pandas).

Note what happened across three lessons: you built the tally pattern by hand, used it on a file, and today Counter(votes) does it in one line. That order was deliberate. Build it once yourself, and the shortcut is never magic — you know exactly what it does, what it costs, and when it's wrong. That's also the rule for AI-written code: the intern may use any toolbox, but you sign for what ships.

The skill of this lesson isn't memorizing libraries — it's the reflex of asking "has someone already built this?" before building it yourself. Usually, someone has.
