3 · Read & play

Repos, commits, and the record

A repository ("repo") is a project's home: its files plus the full history of every change. A commit is one saved change with a message saying what and why. That history is the professional's safety net — any commit can be revisited, nothing is ever truly lost.

Today you'll work entirely in GitHub's web interface — create the repo, drag files in, write the commit message. (The command-line git that professionals also use is one course away; the concepts you learn today are identical.)

Commit messages are letters to future-you. "Add dark-mode toggle to about page" lets next-month-you find the change in seconds. "stuff" does not. Write the letter every time.

And the compounding part: this profile is your public record. Every course on this site ends its builds here. A college admissions reader or a hiring manager who finds twenty real projects, with histories, learns more about you than any transcript can say. Start the record today; it only grows.
