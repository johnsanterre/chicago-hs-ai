3 · Read

Cells, and the play button

A Colab notebook is a page made of cells. A cell holds either text or code. Code cells have a play button on their left edge. Press it and the code runs on a Google computer far away; the result appears right under the cell about a second later.

Three facts that will save you frustration:

Cells run in the order you run them, not the order they sit on the page. If the notebook acts haunted, Runtime → Restart and run all reruns everything top to bottom — the exorcism.

Nothing you do can break your computer. The code runs on Google's machine, not yours. Experiment freely.

Errors are reports, not judgments. Red text is the computer telling you exactly what stopped it. Your AI assistant translates those reports well — paste the error and ask it to explain, not just fix.
