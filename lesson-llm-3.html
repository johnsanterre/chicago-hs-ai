3 · Read

The extraction contract

To use model output in a program, ask for a shape, not a vibe: "Extract as JSON with keys date, place, what. Reply with ONLY the JSON." Then json.loads(raw) turns the text into a real dictionary, and every Python skill applies — store it, loop it, write it to a file.

It will sometimes fail. The model is a plausible-text machine (course 1, always), and sometimes the plausible reply includes chatter around the JSON. json.loads raises; your program's job is to survive: try / except JSONDecodeError / retry, capped at three attempts, returning None if all fail. Ten lines that turn a moody generator into a dependable component.

Two habits complete the contract: validate what parsed (are the keys you need actually there?), and know that professional APIs offer enforced structured-output modes — the guarantee you hand-built is what those automate. Having built it, you'll always know what's behind the curtain.
