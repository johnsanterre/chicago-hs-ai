3 · Read & play

Now questions are cheap

Two storage formats cover nearly everything. CSV — one row per line, commas between fields — opens in Excel and Google Sheets, which means the organization can use it without you. JSON keeps nesting and nulls intact for the next program. Write both; they're three lines each. And keep the quarantine file and cleaning log beside them — the table's paperwork travels with the table.

Then the stage the whole pipeline existed for. Questions against structured rows are one line each: filter the rows, sum a column, group by month. "How many families this spring?" — filter dates, sum the column, done, and the answer shows its work: which rows, which column, reproducible by anyone who runs the line again.

Where does an LLM fit here? Not in the arithmetic. Adding a column with an LLM is paying for the chance of a wrong sum when code sums perfectly. The LLM earns its place at the edges: turning a stakeholder's vague question into the right filter ("spring-ish? let's say March through May"), and phrasing the computed result as a readable sentence for the newsletter. Compute with code; converse with the model. The moment an answer's number comes from anywhere but the table, you've built a very elaborate rumor machine.
