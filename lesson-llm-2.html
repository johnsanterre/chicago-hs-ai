3 · Read

Souls, templates, batches

The system prompt is a standing instruction the model receives before every user message — invisible to users, defining the behavior. "Never rewrite their work; coach instead" turns a general model into a writing coach that holds the line. Every AI product you've used is a system prompt wrapped around the same few models; writing them well is a real craft, and it's the four levers from How AI Works made permanent.

Templates make prompts engineering: f"Write one quiz question about {topic} for a {level} student" — the prompt is now a function of its variables, testable and improvable like any code.

Batching is where code beats chat forever: a list and a loop push a hundred items through the same careful prompt in a minute — a hundred vocab definitions, a hundred caption drafts. One care-fully engineered prompt, amplified by iteration. Watch the token meter when you batch; a loop spends money every pass.
