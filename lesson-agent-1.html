3 · Read & play

Plan, act, observe, repeat

Ask a plain chatbot "how many plots does the Riverside Community Garden have?" and it answers from whatever was in its training data — which may be nothing, or stale, or a confident guess. It cannot go look. An agent can, because an agent is not a different kind of model. It is the same model placed in a loop:

1. Plan — the model reads the question and says what action it needs: "search for riverside community garden plots."
2. Act — your code runs that action and gets a real result.
3. Observe — the result goes back into the conversation.
4. Repeat — the model reads the new evidence and either asks for the next action or answers.

Two things to notice before the figure. First, the model never touches the world — your code is the hands. The model only writes requests, and your dispatch code decides what actually runs. That is a safety property you will keep for the whole course. Second, the answer at the end is different in kind from the chatbot's answer: it can say where each fact came from, because the evidence arrived during the loop instead of being remembered from training. This course builds one specific and useful agent — a research agent, the kind that takes a question and returns a small cited report.
