3 · Read & play

Notes with origins

Now the agent does the legwork. Each angle from lesson 3 becomes a search; each search returns results; the promising ones get fetched. Two mechanical habits and one law make this stage professional.

Habit one: dedupe before fetching. Different angles find the same pages — the news story about the expansion shows up under plot history and under coverage. Fetching it twice wastes a call and, worse, makes one source look like two independent ones later. A set of already-seen URLs, checked before every fetch, fixes it in three lines.

Habit two: notes, not pages. A fetched page is mostly noise. The agent extracts the sentences that bear on the question into a growing notes list — small, quotable, checkable pieces.

The law: every note carries its receipt. Each note is stored with the URL it came from and the date on the page: {"note": "60 plots", "source": "cityparks.gov/report-2026", "date": "2026-03-14"}. Do this at gather time and it costs nothing — the URL is right there in your hand. Skip it and it is gone: an hour later nobody, human or model, can say which of seven pages a number came from. Every later stage of this course — checking claims, resolving contradictions, citing the report — reads that source field. A note without one is unusable for all of it.
