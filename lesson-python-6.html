3 · Read & play

w, r, a — and where the files live

with open("note.txt", "w") as f: opens a file for writing — creating it if needed. f.write(...) puts text in. r reads; a appends without erasing. The with block closes the file for you when it ends — the tidy habit from day one.

In Colab, click the folder icon on the left after writing: your file is really there, on the session machine. Honest note: it vanishes when the session ends — download anything you want to keep. (Real programs on your own computer keep their files; the data course revisits this.)

The build joins two lessons on purpose: a file full of words, read back and fed through lesson 5's tally pattern. Watching old tools combine into new powers is what programming feels like from here on.
