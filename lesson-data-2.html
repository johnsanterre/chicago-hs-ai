3 · Read

Filter, sort, count

Filter — df[df['col'] == value]. Read it inside-out: the inner expression builds a column of True/False; the outer brackets keep the True rows. Comparisons all work: >, <, !=. Every subset you'll ever take is this one shape.

Sort — df.sort_values('col', ascending=False) puts the biggest on top. Sorting is how "who's highest/lowest/newest" questions get answered.

Count — df['col'].value_counts() tallies every category. It's the Python course's five-line tally pattern as a single word — and because you built the pattern by hand there, this shortcut is transparent to you.

The real power is composition: filter first, then count — the grade distribution of heavy internet users. Chain moves and a table starts answering questions a human eyeball never could. One discipline: after each code answer, write the plain-English sentence. Code computes; the sentence is the analysis.
