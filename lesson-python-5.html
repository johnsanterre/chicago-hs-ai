3 · Read

Labels beat positions

A dictionary stores pairs: {"name": "Maya", "points": 31}. You ask by label — player["points"] — instead of remembering that points happened to be item 2. Labels beat positions whenever you're storing facts about a thing.

Dictionaries nest: a contact book is a dictionary of names, where each value is another dictionary (phone, birthday, favorite food). Most real-world data — every API response you'll meet in the data course — is shaped exactly like this.

And learn the tally pattern by heart:

tally[v] = tally.get(v, 0) + 1 inside a loop counts anything — votes, words, dice rolls. .get(v, 0) means "the count so far, or zero if we've never seen it." Five lines, endless uses; next lesson a library does it in one line, and you'll know exactly what that shortcut is doing.
